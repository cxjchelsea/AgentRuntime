## 2. 关键源码兼容依据

- `runtime/orchestration/runtime.py`：固定一轮流程，从 M3/M4/M5 到 Response/Update；存在 `LEGACY_TEST_COMPAT` 与 `DENY_ONLY_GATED`。不得在 Loop 中无设计地重复调用全量 `run()`。
- `runtime/understanding/engine.py`：`RuntimeUnderstandingEngine` 已有可选 `StructuredUnderstandingModel`。
- `runtime/planning/runtime_integration.py`：`DefaultM4Planner`、`RuntimePlanValidatorAdapter`、`RuntimePolicyRecheckerAdapter` 已有实现。
- `runtime/planning/strategy_selection.py`：模型仅在合法 Action/Strategy 范围内软选择。
- `runtime/contracts/planning.py`：`ActionPlanDraft`（DRAFT）和 `ApprovedActionPlan`（APPROVED）不得混淆。
- `runtime/contracts/execution.py`：`ExecutionResult` 是执行观察，不是业务真值。
- `runtime/contracts/validation.py`：`ValidatedResult` 有验证状态、可表达声明和事实。
- `runtime/planning/replan.py`：`ReplanEntryRequest` 只是 deferred entry，`trigger_stage` 仅 `RESULT_VALIDATE`。
- `runtime/execution/capability_execution.py`、`aggregation_runtime.py`：M5 实际执行与聚合存在，不可重做。
- `runtime/validation/no_grant_downstream_policy.py`：NoGrant 阻断后续 Response/State/Memory 和 Positive Claim。
- `runtime/registries/domain.py`、`prompt.py`：只登记元数据，不提供真实 Package 加载与 Prompt 调用。
- `runtime/state_management/engine.py`：RuntimeStateEngine 已有独立转移控制，不能被新的 AgentRunState 替代。

## 3. 阻塞清单与建议补救

### B-01（GA-01 实施阻塞）：Loop 的调用点不明

问题：现有 Runtime Orchestrator 负责完整单轮 Response/Update，外层 Loop 直接循环 `run()` 可能导致过早提交状态、重复 Tool 行为或绕过验证。

**补救**：GA-01A 必须绘制可执行 Call Graph，选择通过既有 Engine 接口封装 Task-level Adapter 或安全抽离迭代控制点；给出“一次真实工具物理调用只出现一次”负测与不修改现有 Contract 的兼容证据。禁止平行 Executor。

### B-02（GA-01 实施阻塞）：M6 缺少正向验证权威

问题：现有 NoGrant 明确拒绝发布可信正向事实，不能通过解释性“测试成功”绕开 M6。

**补救**：GA-01A 只能采用显式隔离的 No-Side-Effect Harness、Mock Tool、非生产观察证据；Test-only Truth 在任何生产路径不可被装配。测试需证明 NoGrant 仍阻止 Response/State Update；生产真实授权仍属于 B3/GA-06 独立设计。

### B-03（GA-02 阻塞）：Registry 不是 Loader

**补救**：DomainBinding 的精确版本、依赖清单、命名空间、Knowledge/Prompt/Tool/Policy 绑定与错误处理，在 GA-02 明确并做双领域装配负测。

### B-04（GA-05 阻塞）：长期记忆与状态持久化未证明

**补救**：把 Runtime 控制状态、Domain 状态、Agent Run 状态、用户记忆分离治理；新增 Memory Store 前先评估现有 Provider 和存储接口，禁止多个写入权威。

### B-05（GA-04 追踪）：取消后的 Stage Trace 终态风险

**补救**：针对已知取消时 StageTraceEvent 可能遗留 STARTED 做精确回归/修复，不据此次文档改动宣称已经解决。
