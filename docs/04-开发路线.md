## GA-01 设计中的硬规则

1. 不新增第二套 Planner、Execution Engine、Registry 或 Runtime State Store。
2. Agent Loop 有确定性 Budget/终止/循环抑制；模型输出只能提出候选。
3. Tool 必须来源于已批准 ActionPlan；执行结果要有可归因可信 Observation。
4. `WAITING`、`UNKNOWN`、`PARTIAL_SUCCESS` 不可无证据当 SUCCESS。
5. 模拟工具与真实外部副作用路径**严格隔离**；旧 `LEGACY_TEST_COMPAT` 不等于生产正向授权。
6. 正式执行变更绑定精确 HEAD，完成 pytest、mypy、ruff check、ruff format --check，留下结果。
7. 安全/合同/副作用变更独立审查；普通文档与功能不重复造 Gate。

## 完成 Definition of Done

- **组件完成**：源码、接口、单测、静态检查通过。
- **能力完成**：集成测试 + E2E 实际任务走通，包含失败路径。
- **跨 Domain 完成**：只换 Package，不修改 Core，隔离测试通过。
- **生产完成**：运行环境、正向授权、运维及外部效果证据俱全。
