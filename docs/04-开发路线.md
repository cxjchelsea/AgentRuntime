# 04｜开发路线速览

> **此页仅为速览，不是第二份实施方案。** 全量 Unit、依赖、测试和验收以 [05 通用 Agent 系统总体实施方案 V1.0](05-总体实施方案.md) 为唯一权威；总体产品定位以 [01 总体架构 V2.0](01-总体架构.md) 为准。

| 顺序 | 本阶段可交付能力 | 完成证明 |
|---|---|---|
| GA-00 | 总体设计与复用/风险审查 | 架构、实施和兼容性文档齐备（未冻结） |
| **GA-01A（当前）** | Agent Loop 详细接线与 M6 测试隔离设计 | 关闭 B-01/B-02，明确可执行 Call Graph |
| GA-01B | 最小 Agent Loop | Mock Tool→Observation→再次决策→Finish，负例 fail-closed |
| GA-01C | 结构化真实模型 Adapter | 真实模型隔离任务可复现；不授予生产工具权限 |
| GA-02 | Domain Package 装配 | 版本绑定、缺依赖拒绝、切换有效 |
| GA-03 | 两领域端到端任务 | 同 Core、不改源码、知识/工具/状态隔离 |
| GA-04 | Runtime 深度集成 | 可靠性、Trace、失败/取消与受限验证不变量保持 |
| GA-05 | 高级行为与长期记忆 | Replan/Reflection、跨轮 Task、时效与隔离 |
| GA-06 | 生产 Agent | 正向授权、Composition Root、部署和运行证据 |

**当前决定**：先做 GA-01A 设计，不直接编写 GA-01B。其余实施顺序可按照真实任务反馈调整，但必须更新权威方案。

**质量要求**：真正修改代码后才运行并报告 pytest、mypy、ruff check、ruff format；本轮文档整理没有执行这些门禁。历史 Gate/Closure 不代表生产 Agent 可用。
